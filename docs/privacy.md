# DOROKEI プライバシーポリシー

最終更新: 2026年11月21日

DOROKEI（ドロケー×人狼）は、トモアキ（Sign Link）が提供する、オフラインで遊べるゲームです。

## 収集しない情報

本アプリは、氏名・メールアドレス・電話番号・位置情報・連絡先・写真・端末識別子などの
個人情報を一切収集しません。アカウント登録もありません。

## 通信・広告・解析

- 広告を表示しません。
- アクセス解析（アナリティクス）やクラッシュ収集の外部SDKを組み込んでいません。
- ゲームの進行はすべて端末内で処理され、外部へ送信されません。
- オンライン対戦はありません（CPUとの対戦のみ）。

## 端末内に保存する情報

音量・サウンドON/OFF・言語・制限時間・選んだステージなどの設定だけを、端末内の
localStorage に保存します。アプリを削除すると消えます。

## 写真・マイク・カメラなど

本アプリは、カメラ・マイク・写真・連絡先・位置情報などの端末機能へのアクセスを要求しません。
